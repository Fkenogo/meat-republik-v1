# Purpose

This document defines how every constitutional statement, capability, framework, standard, requirement and implementation artefact is linked across the Meat Republik knowledge repository.

It establishes traceability without requiring duplication.

# Mandatory Traceability Metadata

Every governed document should declare where applicable:

- Constitutional Source
- Governing Instrument
- Governing Doctrine
- Governing Principles
- Enterprise Domain
- Governed Capability
- Parent Framework
- Upstream Dependencies
- Downstream Deliverables
- Related Documents

# Traceability Rules

1. Traceability shall flow from higher authority to lower authority.
2. A document may reference many upstream documents but has one primary governing document.
3. Documents should reference rather than duplicate authoritative content.
4. Every implementation artefact should be traceable to at least one capability and one governing framework.
5. Evidence should trace back through implementation to constitutional intent.

# Founder Note

Traceability exists to explain why something exists, who governs it and how it contributes to the Republic. It should make change safer and understanding easier, not increase administrative effort.

# 1. Purpose

MR-EA-001 defines the complete knowledge architecture of the Meat Republik programme.

It answers:

- What domains exist?
- How they relate.
- Which programmes belong to each domain.
- Where every repository document belongs.
- The order in which the Republic is developed.

It is an architectural map rather than a constitutional document.

# 5. Architectural Rules

1. Every document belongs to one programme.
2. Every programme belongs to one enterprise domain.
3. Every domain declares governing dependencies.
4. Constitutional content shall not be duplicated across domains.
5. Lower domains consume constitutional guidance rather than reinterpret it.

# Founder Note

The Enterprise Architecture exists to make the Republic understandable before it becomes extensive. It provides the map that every future document follows, ensuring growth through structure rather than accumulation.

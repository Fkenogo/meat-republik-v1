# 1. Purpose

This standard defines how repository documents are classified, how authority is assigned, and how relationships between documents are expressed.

It governs the repository, not the Republic itself.

This is a **Meat Republik project standard** and is intended to align with any future Founder Repository Architecture Standard (FRAS) adopted through the FEF.

---

# 2. Guiding Principles

- One document, one primary purpose.
- Authority shall be explicit.
- Higher-authority documents govern lower-authority documents.
- Lower-authority documents shall not contradict higher-authority documents.
- Every governed document shall declare its class and authority level.

---

# 5. Governance Rules

1. A document may only govern documents at the same or lower authority level.
2. A lower-authority document must identify its governing document(s).
3. Conflicts are resolved in favour of the higher authority.
4. Constitutional Source documents are not superseded by implementation documents.

---

# 6. Mandatory Metadata

Every governed document shall declare:

- Document ID
- Title
- Version
- Status
- Document Class
- Authority Level
- Parent / Governing Documents
- Repository Domain

---

# 7. Relationship Matrix

Every governed document shall include a relationship matrix identifying:

- Constitutional Source (if applicable)
- Parent
- Governing Document
- Interpreting Document (if applicable)
- Applying Document (if applicable)
- Related Documents

---

# 8. Future Alignment

This standard is project-specific.

When the Founder Engineering Framework adopts a Founder Repository Architecture Standard (FRAS), this document shall be reviewed and aligned through governed change rather than informal restructuring.

---

# Founder Note

The purpose of this standard is consistency, clarity and traceability—not bureaucracy. It provides a common language for the Meat Republik repository while remaining intentionally compatible with future cross-project governance.
